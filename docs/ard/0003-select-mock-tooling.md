# ADR-0003: モック駆動開発の補助製品

状態: **Proposed** / 提案日: 2026-09-13

Storybook・MSW・Playwright を組み合わせる案である。このリポジトリーの UI・JSON・SSE への適合性は未確認であり、[U11](../../PLAN.md#u11) で採否を決める。

- **要件・リスク:** 本番用 UI の状態確認、HTTP 応答の再現、主要操作の検証を反復したい。
- **追加しない場合:** 状態への到達操作や確認を繰り返す負担が残る。
- **単純な案との比較:** 本番用アプリ＋MSW＋Playwright を最小案とし、状態を直接開く価値があれば Storybook を加える。独自の状態確認基盤は実装・保守負担のため選ばない案とする。
- **今検討する理由と負担:** モックを作り始める前に、状態数に対する Storybook 設定・Story 保守の負担を判断する。現時点で導入必須とはしない。

代表画面で、本番用 UI の表示・応答再現・操作検証が過大な追加実装なしに成立することを確認してから採否を決める。Storybook の維持負担が利点を上回る場合は最小案とする。

候補・導入状況・実行手順は [ツール文書](../mock-tooling.md)、プロセスの採否は [ADR 0002](0002-adopt-mock-driven-development.md) に分ける。
