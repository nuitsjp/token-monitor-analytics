# ADR-0002: 本番用 UI を共用するモック駆動開発

状態: **Proposed** / 提案日: 2026-09-13

本番用 UI をモック応答で動かして合意し、同じ UI を実処理へ接続する案である。動くものによる認識合わせが必要な変更に限る。採否は [U10](../../PLAN.md#u10) で扱い、文書統合を採用承認とはみなさない。

- **要件・リスク:** 画面・操作・表示状態について、人と AI の認識のずれを実装を広げる前に確かめたい。
- **追加しない場合:** 実処理を先に完成させると、操作確認までの実装範囲と手戻りが大きくなり得る。
- **単純な案との比較:** 使い捨てモックは本番への作り直しと再解釈が必要になる。本番用 UI の共用で、確認した内容を引き継ぐ。
- **今検討する理由と負担:** 初期 UI の実装前に進め方を揃える。一方、初期から UI 実行環境とモックの保守が必要で、実処理との差異確認も残る。

実施ルール案は [モック駆動開発](../standards/mock-driven-development.md)、このプロジェクトへの適用状態は [文書方針](../document-policy.md#mock-development) に置く。補助製品の採否は [ADR 0003](0003-select-mock-tooling.md) と分ける。
