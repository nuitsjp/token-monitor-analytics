# T-040 T01 ウィンドウ手動証跡

自動試験で再現できない Windows のウィンドウ管理は、パッケージ済みアプリで次を確認し、画面録画またはスクリーンショットと実行環境を記録する。

- T01 が起動直後から最前面で、最小化ボタンとトレイへの隠蔽がなく、他アプリへ切り替えた後の定期更新でフォーカスを奪わない。
- T01 の折りたたみ幅が 360 DIP、展開幅が 420 DIP で、展開時の高さが現在モニターの作業領域の 50% 以下になる。利用枠領域だけが縦スクロールし、タイトルと操作部が切り取られない。
- T01 を各画面端から 16 DIP 以内へ移動したとき端へ吸着し、再起動後に位置・展開状態・モニターが復元される。
- T01 を表示したモニターを切断し、解像度または DPI を変更した後、T01 が利用可能な作業領域内へ戻り、文字と操作部が切り取られない。
- T01 から M00 を開いたとき、可能な場合に M00 が T01 と重ならない画面端へ配置される。M00 は一つだけ生成され、再度開く操作は既存画面を前面へ出す。
- T01 の Alt+F4 または閉じる操作で収集停止の確認を表示し、停止完了後に T01・M00・アプリ全体が終了する。M00 の Alt+F4 は M00 だけを閉じ、T01 と収集を残す。

記録項目: Windows 版、DPI（100/125/150%）、モニター台数と配置、主モニター、作業領域サイズ、実行日時、確認者、各項目の結果、証跡ファイルの SHA-256。
