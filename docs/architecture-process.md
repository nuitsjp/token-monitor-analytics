# アーキテクチャ設計の参考

設計・実装の進め方と文書作業の区切りは [文書方針](document-policy.md)、現在の作業範囲は [開発計画](../PLAN.md) に従う。本書は説明が必要になった時に選ぶ手法の参考資料とする。

| 手法 | 利用する場面 |
| --- | --- |
| [arc42](https://arc42.org/overview/) | 構造、実行時動作、判断理由のうち、説明が不足する観点を確認する。 |
| [C4 model](https://c4model.com/diagrams) | システム境界、実行単位、内部の責務を図で説明する。対象に合う図だけを選ぶ。 |
| [4+1 ビュー](https://www.cs.ubc.ca/~gregor/teaching/papers/4%2B1view-architecture.pdf) | 並行処理や主要シナリオから、責務間の相互作用を確認する。 |

必要な説明には既存の図・文章・コード・テストを利用できる。本書は必須成果物や独立した初期設計の完了審査を設けない。
