# Token Monitor Analytics デザインシステム

## 1. 文書の位置付け

本書は、Token Monitor Analytics の UI 実装で使用するデザイントークン、書式、部品、状態表現を定義する。画面の構成と遷移は `screen-design.md`、採用技術は `architecture.md` を正とし、本書は見た目と振る舞いの共通規則だけを定める。

参照実装イメージ:

- 画面サンプル: `design-samples/screens.html`（T01 / M01 / M02）
- 部品ギャラリー: `design-samples/design-system.html`

## 2. デザイン原則

1. **ミニマル** — 画面には主要な値と状態だけを置く。規則の説明、集計方法、注意書きは常時表示せず、ツールチップと詳細画面へ退避する。
2. **色と形で意味を伝え、色だけに依存しない** — 状態はアイコン + 色 + ツールチップの組で表現する。系列の区別には塗りとパターン（斜線）を併用する。
3. **内部 ID を見せない** — 画面 ID（M01 等）、Phase 区分、実装用語を UI に表示しない。遷移はカード全体のクリックとシェブロン（›）で示す。
4. **日本語話者の慣習に合わせる** — 日時は `8/27 14:00` 形式。当たり前の情報（表示タイムゾーン名など）は常時表示しない。
5. **Fluent UI React v9 に準拠** — 独自部品は Fluent のトークンと寸法に合わせ、上書き CSS を最小にする。

## 3. デザイントークン

## 5. 書式

### 5.1 日時

表示タイムゾーンは表示設定で管理し、画面上にタイムゾーン名を常時表示しない。

| 対象 | 形式 | 例 |
| --- | --- | --- |
| 当日 | `H:MM` | `9:03` |
| 当年 | `M/D H:MM` | `8/17 3:00` |
| 年跨ぎ | `YYYY/M/D H:MM` | `2025/12/31 23:59` |
| 相対時間 | 絶対時刻の後に括弧書き、または単独時はツールチップに絶対時刻 | `9:03（5分前）` |
| リセット予定 | `M/D H:MM リセット` | `8/27 14:00 リセット` |
| 期間 | `M/D 〜 M/D` | `8/1 〜 8/25` |

- 時は 24 時間制・先頭ゼロなし。分は 2 桁。
- 鮮度が劣化した日時（8 日前など）は警告色 #bc4b09 で表示し、ツールチップに絶対時刻と経過時間を併記する。

### 5.2 数値

| 対象 | 表示 | 詳細（ツールチップ・詳細画面・出力） |
| --- | --- | --- |
| トークン数 | 3 桁区切り整数 | 同じ |
| USD | 小数 2 桁 + ` USD` 後置 | 小数 6 桁 |
| 残量・割合（ゲージ併記） | 小数 1 桁 | 小数 2 桁 |
| 倍率 | 小数 2 桁 | 同じ |
| 残高・クレジット・従量額 | 元の単位のまま。パーセントへ変換しない | 同じ |

- API 換算利用額には `*` を付け、ツールチップで「API 単価による換算値。実際の請求額ではありません」と 6 桁値を示す。
- 保存値・再計算・出力には表示丸め値を使用しない（`screen-design.md` 8.2）。

### 5.3 残量ゲージの閾値

| 残量 | 色 | 文字色 |
| --- | --- | --- |
| 50% 超 | #107c10（緑） | #0e700e |
| 20–50% | #eaa300（琥珀） | #9d5d00 |
| 20% 未満 | #d13438（赤） | #bc2f32 |
| 不明・経過済み | トラックのみ（#e6e6e6） | #616161 |

「残り」等のラベルは表示しない。ゲージ + 色付き % + ツールチップ（`残り 38.20%・利用増加 3時間前・最新観測 5分前`）で伝える。

## 8. 状態と空表示

- 読込中は値の位置を維持するスケルトン。直前値を出す場合は `更新中` と元の観測時刻を併記する。
- 成立しない指標は `—` とし、理由はツールチップと詳細画面で示す。ゼロと不明を混同しない。
- `取得失敗あり` `重複要求スキップあり` `集計対象外あり` は警告バッジで示し、対象の履歴・内訳へ遷移できるようにする。
- ゼロ件の正常状態（処理失敗 0 件など）はカウントボタンを表示しない。詳細画面では `0` を表示してよい。

## 9. アクセシビリティ

- 状態は色 + アイコン + ツールチップ文字列の 3 点で伝える。グラフ系列は塗り + パターンで区別する。
- アイコンのみの操作部に `aria-label`、ゲージに `role="img"` と `aria-label`（例: `Codex 残り 38.2%`）を付ける。
- ツールチップへ退避した情報はスクリーンリーダーからも到達できるようにする（Fluent Tooltip はフォーカスで表示）。
- キーボード操作・フォーカス表示・ハイコントラスト・200% 拡大への対応は Fluent 標準部品の挙動を優先する（`architecture.md` 6.3）。

## 10. screen-design.md との差分

本デザイン採用に伴い、次の表示規則は `screen-design.md` の記載から意図的に変更している。設計書側の更新が必要である。

| 項 | screen-design.md | 本書 |
| --- | --- | --- |
| 8.2 USD 表示桁 | 小数第 6 位 | 表示は 2 桁、詳細・出力は 6 桁（§5.2） |
| 6.1 残り（%）表示桁 | 小数第 2 位 | ゲージ併記は 1 桁、詳細は 2 桁（§5.2） |
| 各所の注記常時表示（`取得済み観測の合計` 等） | 画面へ明記 | ツールチップと詳細画面で提示（§2-1） |
| タイムゾーン名の常時表示 | カード直下等へ表示 | 表示設定へ集約し常時表示しない（§5.1） |
| 「残り」ラベル | `残り 38.20%` | ラベルなし・色付き % + ゲージ（§5.3） |

集計規則そのもの（共有を按分しない、推定の明示、絶対量を % 化しない等）は変更しない。
