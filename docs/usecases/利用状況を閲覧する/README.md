# 利用状況を閲覧する

## 主アクター

利用者。

## 目的

登録Hubとデバイスの最新状態を、ダッシュボードのひとつの画面で確認します。

## 前提

アプリケーションが起動し、Hubが接続設定へ登録されています。

## 共通の受け入れ条件

画面を開いた時に一度取得し、以後の保存通知は「閲覧中の利用状況を自動更新する」で反映します。手動更新は行いません。

## 集計と利用枠の分岐条件

「全Hub統合情報を表示する」「モデルトークン構成比を表示する」「利用枠を表示する」は、「Hubとデバイスの最新利用状況を表示する」でHub・デバイスを表示した後、または「閲覧中の利用状況を自動更新する」の更新通知を受信した時に分岐します。前提として、トップ画面が開かれ、Hub情報が取得されている必要があります。
