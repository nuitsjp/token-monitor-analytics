# ツール別のトークン構成比を表示する

- 種別: 拡張
- UI確認: 要

## 目的

選択した期間のトークン使用量をツール別に比較し、全体に占める割合を確認します。

## 分岐条件

「Hubとデバイスの最新利用状況を表示する」でトップ画面を開いて登録Hubの最新保存状態を取得した後、期間切替時、または「閲覧中の利用状況を自動更新する」の更新通知を受信した時。

## UI確認内容

ツール別の数値・構成比、期間切替、使用量がない場合の表示を確認します。

## 補足

[UCP-2](../../../design/UCP-2.md) を適用します。初回取得と共通更新通知にツール別内訳を含め、共有データから表示します。テーブル変更はありません。

## 手順

1. アプリケーションが登録Hubの最新保存状態から、期間別のツール別トークン数を返します。
2. 画面が選択期間について、受信済み全Hubの同じツールのトークン数を合算します。
3. 画面が各ツールのトークン数を全ツールの合計で割り、構成比を算出します。
4. 画面がツール欄に、使用量順の一覧と構成比の棒グラフを表示します。
5. 利用者がTODAY・MONTH・TOTALを切り替えます。
6. 画面が選択された期間で集計し直し、表示を更新します。
7. 画面が「閲覧中の利用状況を自動更新する」の更新通知を受けるたびに、選択期間を維持して表示を更新します。

## 受け入れ条件

- ツール欄の固定サンプルを保存データに置き換え、この欄の「固定サンプル」表示を削除します。
- 「最も利用したツール」およびその専用表示は設けません。
- 集計元は各Hubの `stats.periods.today / month / allTime` にある `clients` とします。同じツール識別子をHub間で合算し、デバイス別の値は重ねて加算しません。未受信Hubは集計に含めません。
- 構成比の分母は、選択期間の全ツールのトークン数合計とします。
- 各ツールの名前、カンマ区切りの整数のトークン数、小数第1位までの構成比、構成比に比例した棒を表示します。割合は個別に丸めるため、表示上の合計が100%にならない場合があります。
- ツールはトークン数の降順で全件表示し、「その他」への集約は行いません。同数の場合はツール識別子の昇順とします。
- 受信済みHubがない場合は「まだ情報を受信していません」と表示します。受信済みで全ツールの合計が0の場合は「この期間のトークン使用量はありません」と表示します。
- 期間切替と自動更新に連動します。通知接続の切断中は最後の表示を保持し、再接続後に最新値へ更新します。
- 初回取得失敗時はツール欄にも取得失敗を表示し、使用量0や固定サンプルで代替しません。
- 今回の対象はツール別トークン構成比です。ツール別コストなど他パーツの実データ化は含めません。モデル欄は「モデルトークン構成比を表示する」で扱います。
