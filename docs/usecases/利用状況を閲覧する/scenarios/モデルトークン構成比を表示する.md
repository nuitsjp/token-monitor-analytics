# モデルトークン構成比を表示する

- 種別: 拡張
- UI確認: 要

## 目的

ダッシュボードの「モデル」欄に、全Hubの受信情報に基づくモデル別のトークン消費量と構成比を表示します。

## 分岐条件

[集計と利用枠の分岐条件](../README.md#集計と利用枠の分岐条件) に従います。

## UI確認内容

モデル欄の実データ反映、モデル別トークン数と構成比バーの描画、期間切り替え（TODAY / MONTH / TOTAL）への連動、更新通知時の自動反映、未受信時・利用データなし時の表示を確認します。

## 手順

1. 画面が共有データ（全Hubの最新状態）から、選択中期間の全Hubのモデル別トークン数を集計します。
2. 画面が各モデルのトークン数と全モデル合計に対する構成比（%）を算出します。
3. 画面が「モデル」欄へモデル別のトークン数と構成比バーを降順で表示し、「固定サンプル」バッジを削除します。
4. 利用者が期間（TODAY / MONTH / TOTAL）を切り替えます。
5. 画面が選択された期間に合わせて、モデル別トークン数と構成比を再集計して表示を更新します。
6. 画面が「閲覧中の利用状況を自動更新する」によるデータ更新を受信した際、モデル別トークン数の集計、構成比の算出、モデル欄への表示を自動で再実行します。

## 受け入れ条件

- ダッシュボードの「モデル」パネルが固定サンプルから保存データに基づく値に置き換わり、「固定サンプル」バッジが削除されます（実データ反映済みの箇所はバッジなし）。
- 集計対象は、受信済み全Hubの選択中期間（TODAY・MONTH・TOTAL）におけるモデル別トークン数（`models`）とし、全Hub合算で集計します。
- モデル一覧はトークン数の降順で並べ、各行にモデル名、トークン数（カンマ区切り整数）、構成比（%）、および構成比に対応するプログレスバーを表示します。
- トークン数の多い上位9モデルを表示し、10件目以降は「その他」として合算して10行目に中立色で表示します（その他を含めて最大10件。モデル総数が9件以下の場合は全件表示し、「その他」は表示しません）。
- 受信済みHubが存在しない、または選択中期間のモデル別トークン合計が0の場合は、「利用データがありません」と表示し、固定サンプルは表示しません。
- 期間切り替え（TODAY / MONTH / TOTAL）に連動して各モデルの集計値および構成比が切り替わります。
- 自動更新（「閲覧中の利用状況を自動更新する」）でHubの最新状態が届いた場合、モデル構成比も再読み込みなしで即座に更新されます。
- テーブル変更はありません（既存の `hub_states.stats_json` 内の `periods[period].models` を利用）。
