# 閲覧中の利用状況を自動更新する

- 種別: 拡張
- UI確認: 要

## 目的

再読み込みせずに最新の保存済み利用状況を確認します。

## 分岐条件

「Hubとデバイスの最新利用状況を表示する」の初回API取得に成功し、Hub・デバイスを表示した後。

## UI確認内容

数値の更新、期間選択の維持、切断時の表示を確認します。

## 手順

1. 画面の共通受信処理が更新通知への接続を開始します。
2. アプリケーションが接続時点の最新保存値を通知します。
3. 画面の共通受信処理が共有データを受信した全体状態で置き換えます。
4. 画面が共有データを参照する各コンポーネントの数値・構成比・受信状態を更新します。
5. 画面が「Hubの最新情報を保存して通知する」の保存後通知ごとに、共有データを全体状態で置き換え、各コンポーネントの数値・構成比・受信状態を更新する処理を繰り返します。
6. 画面の共通受信処理が画面を閉じたら共通接続を終了します。

## 受け入れ条件

- 実データに接続済みのHub別トークン数・推定コスト・合計・構成比、Hub数・デバイス数・取得時刻が自動更新されます。
- 未受信Hubは、初回保存の通知を受けた時点で受信済みの表示に変わります。
- TODAY・MONTH・TOTALの選択を維持し、選択中の期間の値を更新します。
- ブラウザーのアプリケーションごとに接続を1本だけ持ち、コンポーネント数に応じて増やしません。後から表示するコンポーネントも共有データの最新値を参照します。
- 初回API取得と通知接続の間の更新は、接続時の最新保存値で補います。
- 切断時は最後の値を保持して「再接続中」と表示し、再接続後に最新保存値へ追いつきます。
- 受信ごとに全体を置き換え、使用量を加算しません。
- 手動更新と、固定サンプルの他パーツの実データ化は対象外です。初回取得失敗の振る舞いは「Hubとデバイスの最新利用状況を表示する」を維持します。
