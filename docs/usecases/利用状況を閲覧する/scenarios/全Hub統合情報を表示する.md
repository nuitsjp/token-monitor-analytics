# 全Hub統合情報を表示する

- 種別: 拡張
- UI確認: 要

## 目的

画面上部の主要指標（トークン、推定コスト、アクティブ日数）に、全Hubの受信情報に基づく集計結果を表示します。

## 分岐条件

[集計と利用枠の分岐条件](../README.md#集計と利用枠の分岐条件) に従います。

## UI確認内容

画面上部KPI（トークン・推定コスト・アクティブ日数）の実データ反映、期間切り替えへの連動、未受信時の表示を確認します。

## 手順

1. 画面が共有データ（全Hubの最新状態）から、選択中期間の全Hub合計トークン数と合計推定コストを算出します。
2. 画面が共有データから、全Hubのアクティブ日数を集計します。
3. 画面が画面上部の主要指標欄（トークン、推定コスト、アクティブ日数）へ算出した値を表示します。
4. 利用者が期間（TODAY / MONTH / TOTAL）を切り替えます。
5. 画面が選択された期間に合わせて、トークン数・推定コスト・アクティブ日数を再計算して表示を更新します。
6. 画面が「閲覧中の利用状況を自動更新する」によるデータ更新を受信した際、共有データからの集計と画面上部の主要指標欄への表示を自動で再実行します。

## 受け入れ条件

- 画面上部の「トークン」「推定コスト」「アクティブ日数」が固定サンプルから保存データに基づく値に置き換わります。「保存値」ラベルはすべて削除し、未更新のパーツにのみ「固定サンプル」を表示します（実データ反映済みの箇所はラベルなし）。
- トークン数は、受信済み全Hubの選択期間（TODAY・MONTH・TOTAL）の `totalTokens` の合計値を、カンマ区切りの整数で表示します。
- 推定コストは、受信済み全Hubの選択期間の `costUsd` の合計値をドル換算（`$X,XXX.XX` 形式）で表示します。
- アクティブ日数は、全Hubの受信データから算出した日数を整数で表示します（受信済みHubの `activeDays` の最大値）。
- 受信済みHubが0件の場合は、トークン `0`、推定コスト `$0.00`、アクティブ日数 `0` とし、未受信Hubは集計に含めません。
- 期間切り替え（TODAY / MONTH / TOTAL）に連動して各指標の集計期間が切り替わります。
- 自動更新（「閲覧中の利用状況を自動更新する」）でHubの最新状態が届いた場合、上部指標も再読み込みなしで即座に更新されます。
- テーブル変更はありません。
