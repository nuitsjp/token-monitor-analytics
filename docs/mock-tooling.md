## 現在と構成案

現行の実行設定はない。[退避した package.json](../old/package.json) には Node.js のテスト、独自 Mock Hub、`@playwright/cli` があるが、以下の構成を導入済みとは扱わない。設計方針の Mock Hub 同梱要件は維持する。

| 候補 | 用途 | 配置案 |
| --- | --- | --- |
| Storybook | 本番用 UI の画面・部品の状態を直接開いて確認する。 | 対象 UI と同じ場所。 |
| MSW | HTTP 応答を再現する。 | モック定義の正本を一か所に置く。 |
| Playwright | 主要シナリオの受け入れテスト。 | テスト配置の決定時に定める。 |

UI の構成、ブラウザと Analytics 間の JSON・SSE、Analytics と Hub 間の通信のどこを再現するかは未決である。MSW と Mock Hub の役割を確認し、MSW のために HTTP 層を追加しない。

## 採用後の使用ルール

- Story・モック・テストは [設計書の S1〜S9](architecture.md#runtime) の該当 ID で対応付ける。
- HTTP 応答は既存の型・API 仕様に合わせ、共通の MSW 定義を再利用する。
- 画面遷移はアプリで確認し、Storybook に再実装しない。
- 実接続・本番では通信モックを無効にし、モックへ自動フォールバックしない。
