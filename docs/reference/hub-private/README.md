## 保存内容

各ファイルは API レスポンス本文をそのまま UTF-8 で保存した実データです（アカウント識別情報や端末名等を含むため取り扱いに留意）。

| ファイル | GET エンドポイント | 結果・内容 |
| --- | --- | --- |
| `health.json` | `/api/health` | 200: 稼働状態と Hub のビルド識別情報 |
| `stats.json` | `/api/stats` | 200: 集約した利用実績・利用枠 |
| `devices.json` | `/api/devices` | 200: 2台分の端末別実績・利用枠・保持履歴 |
| `history.json` | `/api/history` | 200: Hub が保持する集約履歴 |
| `subscriptions.json` | `/api/subscriptions` | 200: Hub の契約設定 |
| `public-stats.json` | `/api/public/stats` | 404: 取得不能だった応答の記録 |
| `stream-snapshot.sse` | `/api/stats/stream` | 200: 接続時の初回 snapshot イベント |
| `manifest.json` | — | 取得元、リクエスト開始・終了日時、HTTP 状態、バイト数、SHA-256 |

## 範囲と制約

取得対象は、上流リポジトリ（コミット `2f60827e`）の Worker Hub 実装にある参照用 API です。各 GET レスポンス全体を保存しており、更新・削除 API は実行していません。

本資料の利用にあたっては、以下の制約に留意してください。

- **単発調査のデータ**: 取得時点で参照 API が公開したデータであり、Hub 内部ストレージ全体のバックアップではありません。また SSE も初回イベントのみであり、継続接続の検証データではありません。
- **独立リクエスト**: 各 API は独立して並行取得されたため、単一トランザクションのスナップショットではありません。ファイル間の取得時刻や各端末・利用枠の更新時刻にはずれがあります。
- **推定の前提**: 単一時点のデータ取得であるため、利用許容量の推定に必要な「異なる2時点の有効な観測」を満たすものではありません。
