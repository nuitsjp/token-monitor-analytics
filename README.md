# Token Monitor Analytics

Token Monitor Analytics は、[Token Monitor](https://github.com/Javis603/token-monitor) の Hub（Cloudflare Workers 等）に接続し、定額制 AI サブスクリプション（Claude や ChatGPT 等）の利用枠を可視化するセルフホスト型ダッシュボードです。実測された「API 換算額」と「消費率」の増分からドル建ての利用許容量を逆算・推定し、継続して記録します。

外部データベースや Docker、クラウドインフラを別途用意する必要はなく、Node.js の単一常駐プロセスとしてローカル環境（Windows / Linux）でシンプルに動作します。同一 LAN や VPN（Tailscale 等）経由でのアクセスに対応し、Basic 認証によるアクセス制御も備えています。

---

## 前提条件

本ツールは各端末から直接トークン利用量を収集するものではありません。利用にあたっては、以下の環境が必要となります。

- **稼働中の Token Monitor Hub**:
  各端末の利用状況を集約している上流の Hub（接続用の URL および共有シークレットが必要）。
- **Node.js 24 LTS**:
  実行環境として Node.js 24 LTS を使用します（[mise](https://mise.jdx.dev/) を利用している場合、本リポジトリの設定により指定バージョンが自動で適用されます）。

※ 動作確認や開発向けに、単体で動作する模擬 Hub（ローカルモック）を同梱しています。

---

## 主な機能

- **利用許容量（ドル換算）の逆算推定**: 「5 時間枠で何ドル分利用できるか」「月額費用に見合う利用ができているか」を、実測した増分（$\Delta\text{Cost} / \Delta\%$）をもとに推定します。
- **停止中の利用実績を自動補完**: アプリケーションの停止中や再接続時に生じたデータの欠落を、Hub 側に保存されている端末別履歴から安全に補完します（観測されていない過去の制限枠や推定値を独自に生成することはありません）。
- **単一プロセスによるシンプルな構成**: 外部データベースや追加プロセスを必要とせず、Node.js の標準機能（SQLite / HTTP / 型除去 TypeScript）を中心に単一プロセスで動作が完結します。
- **シンプルなアクセス制御**: Basic 認証を備えており、同一 LAN 内や Tailscale 等の VPN 経由で手軽にアクセスできます。
- **Web 画面からの Hub 管理**: ブラウザ画面から Hub の登録や停止などの管理操作を行えます。

---

## 全体構成

```text
各端末 (Claude Code / ChatGPT 等)
   │ トークン利用実績・制限枠
   ▼
Token Monitor Hub (上流・既存環境)
   │ SSE: リアルタイム観測
   │ GET: 端末別の利用実績補完
   ▼
Token Monitor Analytics (本ツール / Node.js 単一常駐アプリ)
   ├─ Hub 購読マネージャー (直接受信・自動再接続)
   ├─ 保存・推定ステートマシン
   ├─ 履歴の正本 (ローカル SQLite 1つ)
   └─ Web 配信 (HTTP サーバー / Basic 認証 / ブラウザ向け SSE)
   ▼ (LAN / Tailscale / ループバック経由)
Web ブラウザ (ダッシュボード閲覧 / Hub 管理 / システム更新)
```
