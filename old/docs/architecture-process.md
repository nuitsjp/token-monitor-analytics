# アーキテクチャ設計の参考手法

設計・実装の進め方は [文書方針](document-policy.md)、作業範囲は [開発計画](../PLAN.md) に従う。本書は、設計の説明や可視化が必要になった際に参照する手法の候補である（特定の成果物作成や完了審査を義務付けるものではない）。

| 手法 | 主な用途 |
| --- | --- |
| [arc42](https://arc42.org/overview/) | 構造、実行時動作、判断理由など、説明が不足している観点の整理 |
| [C4 model](https://c4model.com/diagrams) | システム境界、実行単位、内部責務の可視化（必要な図のみ選択） |
| [4+1 ビュー](https://www.cs.ubc.ca/~gregor/teaching/papers/4%2B1view-architecture.pdf) | 並行処理やシナリオに基づくコンポーネント間相互作用の確認 |
